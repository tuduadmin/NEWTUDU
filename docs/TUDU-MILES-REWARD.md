# TUDU Miles Reward Economy — Internal Reference

> Source: TUDU_Miles_Reward_Economy july 5, 2026.docx

## Overview

The TUDU Miles Economy is the rewards and incentive system that powers user engagement, host growth, and long-term loyalty across the TUDU platform. TUDU Miles turns every action — attending events, creating experiences, purchasing boosts, building communities — into meaningful progress inside the app.

**Core principles:** earn Miles from activity and spending; redeem Miles for valuable tools and experiences.

- Users earn **100 Miles for every $1 spent** on the platform.
- Hosts earn additional Miles for event-creation milestones.
- Attendees collect Miles through participation, engagement, and referrals.
- **Redemption rate:** 800 Miles = $1 redeemable value (12.5% effective return).
- **Mile value:** 1 Mile = $0.00125.
- Subscriptions remain cash-based but still generate Miles.

## Mile Economy Limitations

- Miles expire after **24 months** (soft expiry at 18 months, hard at 24, with reminder).
- Lower earn rate applies to non-paying users.
- Subscriptions generate Miles but **cannot be purchased with Miles**.
- Miles **cannot be redeemed for cash withdrawal**.
- Host milestone Miles awarded once per milestone.
- Miles revoked if fraud is detected.
